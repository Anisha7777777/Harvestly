# 🌾 AgriConnect

**AgriConnect** is a smart agriculture platform that directly connects farmers with consumers, eliminating unnecessary middlemen and promoting fair trade. The platform enables farmers to register, showcase their products, and display farm locations, while consumers can explore available produce, compare prices, and place orders efficiently.

---

## 🚀 Features

### 👨‍🌾 Farmer Module

* Farmer Registration
* Farm Location Mapping using Leaflet.js
* Product Listing Management
* Harvest Date Tracking
* Quantity & Price Management

### 🛒 Consumer Module

* Consumer Login System
* Browse Available Products
* View Product Quantities and Prices
* Interactive Farmer Location Map
* Price Transparency Dashboard
* Direct Ordering System

### 📊 Transparency Dashboard

* Compare Farmer Price vs Market Price
* Display Price Differences
* Promote Fair Pricing for Farmers

### 🗺️ Interactive Map

* Farmer locations displayed using OpenStreetMap
* Built with Leaflet.js
* Helps consumers discover nearby farmers

### 🔐 Authentication

* Separate Farmer and Consumer Login
* Local Storage Based Authentication
* Role-Based Dashboard Access

### 🌐 Multilingual Support

* Integrated Google Translate Widget
* Supports:

  * English
  * Tamil
  * Hindi
  * Marathi

## 🎯 Problem Statement

Farmers often receive lower profits due to the involvement of multiple intermediaries in the agricultural supply chain. Consumers also pay higher prices without knowing the actual farmer price.

AgriConnect addresses this issue by creating a direct marketplace where farmers and consumers can interact transparently.

---

## 💡 Solution

AgriConnect provides:

* Direct Farmer-to-Consumer Connection
* Transparent Pricing
* Easy Product Discovery
* Location-Based Farmer Search
* Simple Order Placement Process

This helps increase farmer income while reducing costs for consumers.
